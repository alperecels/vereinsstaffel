# Contributing

This repository holds documentation only. There is no code yet, so contributions are corrections and additions to the documentation pages. 

## Before you start

Work from a handover task and a fictional association. Do not add real association records, names, contact details or quotes from people.

## Suggesting a change

- Say which page you want to change and why.
- If you suggest a feature for the register, name the handover step it would improve and explain why a written checklist is not enough.
- Keep each change small. Where it applies, describe how the change could be tested and how it affects accessibility.
- Say where any outside material comes from and which licence it has. Material of unclear origin cannot be used.

## Review

A maintainer checks the scope of a change and the origin of its material before it is merged. At present the founder reviews all changes.

## Writing

Pages are written in British English and in plain language, because many readers are volunteers without a technical background. Translations must keep the difference between being responsible for a service and actually having access to it.

## Licence

No licence has been chosen yet. See [Licensing](docs/licensing.md) for the proposal and the open decisions.

Rules for code contributions will be added when development starts.
