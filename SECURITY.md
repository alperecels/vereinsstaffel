# Security

There is no software yet. There is no supported release and no promise about response times. Reports about weaknesses in the proposed design in [Architecture](docs/architecture.md) are still welcome.

## Reporting a suspected vulnerability

Report it privately to the maintainer. No private reporting channel has been published yet. Until one is, do not put details of a suspected vulnerability in an issue or a pull request. You can open an issue that only says you have a security concern, and the maintainer will contact you.

Include:

- the affected version or page
- what you observed and what impact it could have
- a description with sensitive details removed

Do not include passwords, tokens or other credentials, or anyone's personal data.

## What happens next

The maintainer assesses the report. Where possible, the maintainer agrees with you when the issue will be made public. If it is appropriate, a security advisory is published.
