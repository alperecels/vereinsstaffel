# Prior art and alternatives

This page compares VereinsStaffel with what associations can already use. None of the options below has been tested yet, so this page does not claim that any of them falls short.

## What VereinsStaffel would add

The unit of work is a transfer of responsibility: one association, a named role, a deputy, an open checklist and a decision to close it. The result is a record of the handover.

A list of services on its own is not new. Aiming at small associations is not, by itself, a reason for a new tool either.

## Planned comparison

Every option is tried on the same fictional case. The outgoing volunteer has left. The successor has to find the deputy, confirm that the outstanding access review has been done and locate the documented recovery route.

The baseline is a written guide with a named deputy, as in [scenario S4](scenarios.md). For each option we record whether the task was completed, how much effort it took, which questions stayed open and who would keep the records up to date. If an existing approach is good enough, we record that as the result.

## Options to compare

| Option | Source | What we would compare | Version tested | Result |
|---|---|---|---|---|
| Written guide with a named deputy | The association's own document | The whole task. This is the baseline. | None yet | Not tested |
| CiviCRM | https://civicrm.org | Whether a membership tool can record who holds a role and who deputises | None yet | Not tested |
| Admidio | https://www.admidio.org | Whether a membership tool can record who holds a role and who deputises | None yet | Not tested |
| Snipe-IT | https://snipeitapp.com | Whether services can be handled like assets that are assigned to a person and handed back | None yet | Not tested |
| midPoint | https://evolveum.com/midpoint/ | How a dedicated identity tool handles role assignments and access reviews | None yet | Not tested |
| Bitwarden | https://bitwarden.com | How its emergency access feature lets a trusted person get in. VereinsStaffel stores no credentials, so only the process is compared. | None yet | Not tested |

Once an option has been tested, its row will give the version used, the effort needed and the gap that remains. A simulation cannot show that one option is better than another.
